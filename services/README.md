# EcomCheck Services

Backend service modules for website auditing.

| Service | Description | Status |
|---------|-------------|--------|
| `crawler.js` | Website fetching, link discovery, platform & page detection | ✅ Phase 2.3 |
| `pageContent.js` | Cheerio-based content parsing & contact extraction | ✅ Phase 2.3 |
| `adsDetect.js` | Meta Pixel, Google Tag, Product JSON-LD detection | ✅ Phase 3.4 |
| `productCrawler.js` | Product page discovery, scoring & deep scan | ✅ Phase 3.6 |
| `productScorer.js` | Product page URL/HTML scoring & shopping signals | ✅ Phase 3.6 |
| `scorer.js` | Compliance scoring engine | ✅ Phase 3.1 |
